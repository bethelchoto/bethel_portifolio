Land Diary – Farm Activity Record‑Keeping Web Application

Overview

Land Diary is a contemporary record‑keeping tool that helps farmers monitor all farming activities. It works on any smart device and is fully usable offline in the field; when a connection becomes available, data automatically syncs to the cloud for safe storage and team access. Data is captured using a universal digital language to ensure consistency and seamless integration.

Architecture

  • Created with a Node.js backend exposing REST APIs.
  • Backend and assets deployed on AWS, leveraging S3 buckets for hosting and file storage.
  • Application data stored in Amazon DynamoDB for scalable, low‑latency access.
  • User authentication and authorization handled by Amazon Cognito (sign‑up/sign‑in, access control).
  • Operational logging, testing, and debugging via Amazon CloudWatch logs and metrics.
  • Frontend built with React.js for a responsive, offline‑first experience.

Visualisation & Reporting

  • Real‑time insights with dashboards that turn raw records into meaningful trends for timely decisions.
  • Exportable reports to .csv and PDF for sharing with teams, consultants, and auditors.

Base Module – What’s Included

  • Fertiliser applications with N, P, K breakdowns
  • Plant protection applications and audit‑ready reports
  • Irrigation quantities tracked over time
  • Harvest records with geographic traceability
  • Monitoring (pests, diseases, beneficials, phenology, and more)
  • Agronomic activity records

Offline‑First, Cloud Sync

  • Use anywhere: capture data without internet access in the field.
  • Automatic sync: when online, records are synced to the cloud—no data loss.

Technology Stack

  • Frontend: React.js single‑page application
  • Backend: Node.js REST APIs deployed on AWS
  • Storage: Amazon S3 for files/exports and static assets
  • Database: Amazon DynamoDB for application data
  • Authentication: Amazon Cognito for user sign‑up, sign‑in, and access control
  • Observability: Amazon CloudWatch for logs, metrics, and debugging

Deployment

  • Deployed on AWS: frontend hosted on S3 (with CDN), backend on managed AWS services; CI/CD with automated builds, environment separation, and secure backups.
