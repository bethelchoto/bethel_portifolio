IntelliAgric: An Intelligent, Integrated Farm Assistant

Overview

IntelliAgric is a full-stack, AI- and IoT-powered farm assistant designed to support African small-scale farmers with real-time soil monitoring, crop disease detection, market forecasting, and an integrated e-commerce platform. Built as a modular microservices system, it combines an ESP32-based IoT device, computer vision for maize leaf disease detection, a stacked regression ensemble for market/yield prediction, and a conversational assistant that refines outputs into clear, actionable guidance.

Authors: Tinotenda Rodney Alfaneti and Bethel Panashe Choto (2024). Full project write-up hosted by Ashesi University: Project report.

Key Capabilities

  • IoT Soil Monitoring ESP32 + DHT11 + DS18B20 + capacitive moisture sensor streaming to Firebase RTDB, with daily aggregation to Firestore and automated analysis (moisture/temperature insights; pH/NPK placeholders pending sensor availability).
  • Maize Disease Detection (CV) Fine-tuned ConvNeXt image classifier trained on African maize leaf disease imagery; backed up by the Kindwise crop.health API for non-maize crops or low-confidence cases.
  • Market/Yield Forecasting Stacking ensemble of six regressors predicts yield using crop, area, temperature, and rainfall (with OpenWeather-driven climate features). Demand is inferred inversely from predicted supply vs historical means.
  • Conversational Assistant GPT-3.5-turbo for intent classification and response refinement (chaining + chain-of-reasoning prompts) to deliver context-aware recommendations and alerts.
  • E-commerce MVC PHP application for farm inputs, produce marketplace, equipment sharing, and land rental.
  • Event-Driven Alerts Scheduled background jobs aggregate disease events and trigger SMS/email alerts (Infobip) beyond a location threshold.

Machine Learning: Models and Deployment

  • Maize Disease Model Dataset: ~7K images across healthy/unidentified plus four disease classes (University of Pretoria; hosted on Hugging Face). Fine-tuned ConvNeXt via Transformers on Colab GPU. Test metrics: accuracy 0.889, precision 0.8852, recall 0.8850, F1 0.851. Deployed on Hugging Face Inference API and consumed via backend endpoint.
  • Market/Yield Model Kaggle-based dataset with features: crop, area, annual rainfall, and temperature. Trained six regressors and combined via stacking ensemble; achieved R² ≈ 0.9325. OpenWeather forecasts supply climate features. Deployed on Google Cloud; accessed by the platform through a secure REST endpoint.
  • LLM Integration GPT-3.5-turbo orchestrates intents: #Predict Agriculture Market, #Predict Crop Disease, #Query Ecommerce Database, and #General. Responses are refined for clarity and farmer usability.
  • Architecture Microservices + Publisher/Subscriber (Firebase as broker) + Event-Driven scheduling (APScheduler).

Technology Stack

  • Frontend React, TypeScript, HTML/CSS; Vercel hosting for the integrated platform UI.
  • Backend Python Flask + Flask-RESTX (Swagger UI), APScheduler, DiskCache; integrations with GPT-3.5-turbo, OpenWeather, Kindwise crop.health, Infobip, GNews.
  • IoT ESP32 (C++/Arduino), DallasTemperature, DHT, ArduinoOTA; Firebase RTDB + Firestore for telemetry.
  • E-commerce PHP (MVC), Paystack payments; marketplace, farm inputs, equipment sharing, and land rental modules.
  • Deployment Multi-service hosting (Hugging Face Inference API, Google Cloud, Vercel, Render/free-tier backends).

Results

  • End-to-end tests across 52 cases; ~87% coverage.
  • CV model generalizes well on held-out images; ensemble forecasting explains ≈93% variance.
  • Real-time soil telemetry with daily aggregation and actionable analysis in the UI.

Limitations & Future Work

  • NPK/pH sensors pending; current values are placeholders. Next iteration will integrate hardware.
  • Upgrade LLM to GPT-4o-class models; migrate free-tier services to robust cloud (e.g., AWS) to avoid cold starts and resource caps.
  • Automated drone scouting pipeline and verification workflow for land/equipment listings.
