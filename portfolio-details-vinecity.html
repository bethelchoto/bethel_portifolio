VineCity Housing Trust – Land Allocation & Payment Management Platform

Overview

VineCity Housing Trust is a backend platform designed to manage land allocation workflows, payment tracking, and project lifecycle operations for a housing trust in Zimbabwe. I designed and implemented the core APIs and infrastructure to streamline administrative operations and reduce manual overhead.

Backend API Design

  • Designed and scaled backend APIs using NestJS and MariaDB to manage land allocation workflows, payment tracking, and project lifecycle operations.
  • Developed automated installment scheduling and financial ledger processing systems to reduce manual administrative overhead.
  • Applied structured API design principles with versioning and consistent error handling throughout the platform.

Financial & Workflow Automation

  • Built automated installment scheduling engines that generate payment plans based on configurable terms and track payment status in real-time.
  • Implemented financial ledger processing with audit trails for all land allocation transactions and payments.
  • Developed reporting workflows to generate summaries of payment statuses, outstanding balances, and project progress.

Infrastructure & Security

  • Deployed backend infrastructure using Docker for containerized, reproducible builds.
  • Hosted on Linux VPS with Nginx reverse proxy configuration for secure production operations and SSL termination.
  • Applied backend security practices including authentication, authorization, and database optimization.

Technology Stack

  • Backend Framework: NestJS (Node.js)
  • Database: MariaDB
  • Infrastructure: Docker, Linux VPS, Nginx
  • Security: JWT, Role-Based Access Control
