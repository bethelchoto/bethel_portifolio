E‑commerce Web Application

Overview

Full‑stack e‑commerce platform built with PHP, HTML, and MySQL. The application enables customers to browse products, manage a shopping cart, securely check out, and track orders, while administrators manage inventory, categories, orders, and users from a dedicated dashboard. The UI is responsive and optimized for performance and accessibility.

Key Features

  • Product Catalog Category filtering, keyword search, and pagination. Individual product pages with images, pricing, stock status, and related products.
  • Shopping Cart & Checkout Session‑based cart with add/update/remove actions, shipping calculations, and order confirmation. Checkout captures customer details and persists orders with line items.
  • User Accounts Registration/login, profile management, and order history powered by secure password hashing.
  • Admin Dashboard CRUD for products and categories, inventory management, order status updates, and basic reporting.
  • Payments (Integration‑ready) Structured to plug in gateways such as PayPal or Stripe; current build supports test/sandbox flows.
  • Security & SEO Input validation, prepared statements, CSRF protection on forms, and semantic markup for better SEO.

Technology Stack

  • Frontend -> HTML5, CSS3, Bootstrap 5, Vanilla JS Responsive layouts, reusable UI components, and graceful progressive enhancement.
  • Backend -> PHP (PDO) Clean PHP controllers and services, parameterized queries with PDO, and session‑based auth.
  • Database -> MySQL Normalized schema for products, categories, users, orders, and order_items with proper indexing.
  • Email & Notifications -> PHPMailer Order confirmations and admin alerts.
  • Deployment -> Apache/Nginx (cPanel/XAMPP) Configured for friendly URLs and environment‑based settings.

Challenges & Solutions

  • Data Integrity & Security Mitigated SQL injection with prepared statements, enforced server‑side validation, and secured sessions.
  • Asset & Image Management Implemented safe file uploads, image resizing, and organized storage under /uploads.
  • Pagination Performance Added database indexes and used efficient COUNT/LIMIT queries for large catalogs.

Future Enhancements

  • Live payment gateway integration (Stripe/PayPal) with webhooks.
  • Product reviews, ratings, wishlists, and coupon/discount engine.
  • Sales analytics dashboard and exportable reports.
  • Public REST API for mobile app integration.
