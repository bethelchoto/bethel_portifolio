PayZaar E-Wallet – Fintech Backend Platform

Overview

PayZaar is a fintech e-wallet platform designed to support secure wallet transactions and financial operations at scale. As Backend Developer at Primus Technology, I architected and maintained the backend services powering the platform, with a strong emphasis on transactional consistency, security, and real-time financial visibility.

Backend Architecture

  • Built scalable backend services using NestJS, TypeScript, and PostgreSQL to support secure wallet transactions and financial operations.
  • Developed RESTful APIs and ledger-processing workflows with emphasis on transactional consistency, auditability, and secure financial data handling.
  • Implemented real-time transaction monitoring using WebSockets (Socket.io), reducing operational visibility delays to minimal latency.
  • Designed a financial ledger system with double-entry bookkeeping principles to ensure accuracy and auditability of all transactions.

Security

  • Built secure authentication and authorization systems using JWT, RBAC, and MFA for administrative and operational users.
  • Applied security-focused engineering practices including input validation, rate limiting, and audit logging to protect sensitive financial data.
  • Implemented automated testing approaches to improve backend reliability and maintainability.

Infrastructure & DevOps

  • Containerized backend services using Docker for consistent environment management across development, staging, and production.
  • Configured Nginx reverse proxy deployments for staging and production environments with SSL termination.
  • Collaborated in Agile development workflows using GitHub Projects / JIRA, code reviews, and iterative sprint delivery practices.

Technology Stack

  • Backend Framework: NestJS (Node.js)
  • Language: TypeScript
  • Database: PostgreSQL
  • Real-time: WebSockets (Socket.io)
  • Security: JWT, RBAC, MFA
  • Infrastructure: Docker, Nginx
  • Project Management: GitHub Projects / JIRA, Agile/Scrum
